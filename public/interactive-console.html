Interactive Accessible Console

Connecting to the PTY...

This mode sends keyboard input directly to the real PowerShell PTY. It is intended for interactive programs such as Python, SSH, git add -p, and terminal editors. Output is maintained in an accessible terminal buffer for screen readers and Braille displays.

Terminal output

Focus Terminal output to navigate lines with Up and Down. Home goes to the first line, End goes to the last line, and Page Up/Page Down move by several lines.

Search terminal output

Search starts from the currently selected output line. Press Enter in the search field to find the next match.

Interactive keyboard input

Type normally. Your typed characters remain visible in this field. Enter sends the command and clears the field. Up and Down request terminal command history without clearing the visible text. Tab requests completion without clearing the visible text. The console keeps a local cursor position so editing remains stable for screen readers and Braille displays.

Working Directory

Choose a folder to open the native Windows folder picker. The selected full path will appear in the field. You can also type a full Windows path manually.

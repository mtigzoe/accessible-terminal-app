Interactive Accessible Console

Connecting to the PTY...

This mode sends keyboard input directly to the real PowerShell PTY. It is intended for interactive programs such as Python, SSH, git add -p, and terminal editors. Output is exposed as individual accessible lines so screen readers and Braille displays can navigate the terminal buffer more reliably.

Terminal output

Focus this output area to review terminal lines with your screen reader or Braille display. New output is added as separate accessible lines instead of replacing one large text field.

Interactive keyboard input

Type normally. Your typed characters remain visible in this field while also being sent immediately to the PTY. Enter sends Enter and clears the local field. Tab, arrow keys, Backspace, Escape, Delete, Home, End, Page Up, Page Down, Ctrl+C, Ctrl+D, and Ctrl+L are sent directly to the PTY.

Interactive Accessible Console

Connecting to the PTY…

This mode sends keyboard input directly to the real PowerShell PTY. It is intended for interactive programs such as Python, SSH, git add -p, and terminal editors. Output is presented as individual focusable lines so screen readers and Braille displays can navigate line by line.

Terminal output

No terminal output yet.

Focus the Terminal output region, then use Up / Down to move one line, Home / End for first and last lines, and Page Up / Page Down to jump by several lines. Press Enter on a line to re-announce it. Braille displays follow the focused line.

Search terminal output

Search starts from the currently selected output line. Press Enter in the search field to find the next match.

Interactive keyboard input

Type normally. Your typed characters remain visible in this field. Enter sends the line and clears the field. Up / Down request terminal command history without clearing the visible text. Tab requests completion without clearing the visible text. Other navigation keys are sent directly to the PTY. The local cursor position is preserved so editing remains stable for screen readers and Braille displays.

Working Directory

Choose a folder to open the native Windows folder picker. The selected full path will appear in the field. You can also type a full Windows path manually and press Enter or choose Set directory.

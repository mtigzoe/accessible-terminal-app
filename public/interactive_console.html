Interactive Accessible Console

Connecting to the PTY…

This mode sends keyboard input directly to the real PowerShell PTY. A terminal-state model keeps the command line stable during history and Tab completion. Basic ANSI colours are shown visually; screen-reader and Braille text stays plain. Output is presented as individual focusable lines for line-by-line navigation.

Terminal output

No terminal output yet.

Focus the Terminal output region, then use Up / Down to move one line, Home / End for first and last lines, and Page Up / Page Down to jump by several lines. Press Enter on a line to re-announce it. Braille displays follow the focused line.

Search terminal output

Search starts from the currently selected output line. Press Enter in the search field to find the next match.

Interactive keyboard input

Type normally. History recall and Tab completion keep the visible command line stable. Enter sends the line. Up / Down request history. Tab requests completion. Other control keys are sent directly to the PTY. Shortcuts: Alt+O focus output, Alt+C focus input.

Command output

Press Enter to run. Up/Down browse history. Tab requests PowerShell completion. Ctrl+C interrupts. Ctrl+L clears the view. Escape clears the command.

Working directory

Changing this directory changes the current PowerShell location. The last directory is remembered on this computer.

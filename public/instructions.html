Accessible Terminal Instructions

Menus, keyboard shortcuts, and setup for screen readers and Braille displays.

← Back to home

Terminal views

  • Interactive Console (interactive_console.html) — default and recommended for screen readers (JAWS, NVDA, Braille). Line-by-line output, stable command field, Tab completion, review mode, and bookmarks.
  • Full Console (console.html) — optional visual xterm.js terminal for interactive TTY programs. Prefer Interactive Console for everyday screen-reader use.

Main menu

Every main page has a Menu button in the top-left corner.

  • Click Menu, or press Alt+M, to open or close it.
  • Use Up / Down (or Home / End) to move between items.
  • Press Enter or Space to open the focused item.
  • Press Escape to close the menu and return focus to the Menu button.

Menu items: Interactive Console (recommended), Full Console (visual / advanced), Instructions, Settings.

Review mode: When you move through older lines, focus stays on your line while new output arrives. You hear a short cue that new output is available. Press Alt+L or Read latest output to jump to the end and resume follow mode.

Full Console shortcuts

ShortcutAction
Alt+MOpen or close the main menu
Alt+F2 or Alt+BOpen the accessible buffer overlay
Alt+TFocus the xterm.js terminal
Alt+EnterSend Enter to the terminal
Alt+ISend Ctrl+C (interrupt)
EscapeClose the accessible buffer

Accessible buffer: Reads the current terminal buffer one line at a time with arrow keys, First/Previous/Next/Last buttons, or Find. Only the current line is shown and announced — the full buffer is never placed in a single large text field (which can trigger “too much to navigate” messages). While the buffer is open, it refreshes when new output arrives.

If Alt+F2 is reserved by your operating system, use Alt+B instead.

Screen reader and Braille tips

  • Prefer the Interactive console for line-by-line navigation and Braille review.
  • Output lines are focusable buttons; Braille displays follow the focused line.
  • Colours on the Interactive console are visual only; accessible text stays plain.
  • Announcements use polite live regions so they do not constantly interrupt navigation.
  • On Full Console, open the accessible buffer (Alt+F2 / Alt+B) to review output without relying on xterm’s own screen-reader mode.

Quick start (Ollama / natural language)

  1. Install Ollama on the computer that will run the model.
  2. Start Ollama.
  3. Open Settings → Natural language shell (nlsh / Ollama).
  4. Wait for the Ollama connection status.
  5. Choose Install Qwen 3.5 9B, Install Llama 3.2, or enter another model name and select Install model.
  6. Select the installed model and enable natural language commands.

No ollama pull command is required.

Windows Electron + Linux Ollama

If Electron is running on Windows and you want the model to remain on Linux, start the app with:

.\scripts\start-electron.ps1

The launcher uses http://cyber.local:11434 by default. The Windows app talks to the Linux Ollama server through the backend proxy. Models stay on Linux.

If the model list says Ollama is unavailable, test the connection from Windows PowerShell:

Invoke-RestMethod http://cyber.local:11434/api/tags

The Linux Ollama server must accept connections from the Windows computer.

Managing models

  • Refresh: asks the configured Ollama server for its installed models.
  • Install model: downloads the model through Ollama's API. This works with remote Linux Ollama.
  • Remove selected model: deletes the selected model from the Ollama server.
  • Selected model: is saved in browser settings and used for natural-language translation.

Large models may take several minutes to download.

Ollama installation

Ollama itself is not silently installed by this app. For security, install the Ollama application using the official installer or package instructions.

Open the official Ollama download page

After Ollama is installed and running, return to Settings. You do not need to type a model-pull command.

Instructions

How to use Accessible PowerShell with a screen reader or keyboard.

← Back to terminal

Overview

The interface has three clear regions:

  • Current path — where you are in the filesystem
  • Output — read-only history of commands and results
  • Command — a text field to type PowerShell commands

There is no canvas terminal grid. Screen readers can tab between path, output, and the command box like any other form.

Command field

Type a PowerShell command and press Enter to run it. Press Tab to complete folder and command names. Use Up and Down arrows for command history.

How to use (screen reader)

  1. When the page loads, wait for “Shell ready” / “Connected to PowerShell.”
  2. Focus lands on the Command field.
  3. Type a command (for example Get-Date or Get-ChildItem) and press Enter.
  4. A short status is announced when the command finishes (succeeded or failed).
  5. Press Alt+F2 or Alt+O (or “Go to output”) to read results in the output box with browse mode / the virtual cursor.
  6. Press Alt+C to return to the command field.

Keyboard tips

  • Enter runs the command
  • Tab completes paths and commands (like PowerShell); Shift+Tab cycles backward
  • Up / Down recall previous commands
  • Alt+F2 or Alt+O moves focus to output
  • Alt+C moves focus to the command field
  • Escape clears the command field

Tab stays in the command field — it does not move focus to the Run button. Completions use your current path so cd per + Tab can expand to a folder under that directory.

Menu

  • Focus the Menu button in the top-left corner.
  • Press Enter, Space, or Down to open the menu and move to the first option.
  • Use Up / Down to move between options; Home / End jump to first or last.
  • Press Enter to choose an option.
  • Press Escape to close the menu and return focus to the Menu button.

Current path across refreshes

The last working directory is saved in the browser. After you refresh the page, the shell restores that path automatically when possible.

Accessible PowerShell

Simple screen-reader friendly shell: current path, output history, and a command box.

Console modes

Under Settings → Console mode, or the menu:

  • Accessible (default) — path, output, and command field. Best for screen readers.
  • Full console — real terminal grid (xterm.js) for vim and interactive programs. Open Full console.

Overview

The accessible terminal page has three regions:

  • Current path — where you are in the filesystem
  • Output — read-only history of commands and results
  • Command — a text field to type PowerShell commands

Keyboard tips (accessible mode)

  • Enter runs the command (or sends input while a command is running)
  • Ctrl+C or Stop sends an interrupt
  • Tab completes paths and commands
  • Alt+F2 or Alt+O focuses output
  • Alt+C focuses the command field
